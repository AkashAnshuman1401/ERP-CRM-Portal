# Mini ERP & CRM System

## Features

- Login Authentication
- Dashboard
- Employee Management
- Customer Management
- Product Management
- Inventory Management
- Sales Challan
- Invoice Printing
- Reports
- Excel Export
- Revenue Dashboard Charts
- LocalStorage Data Persistence

## Technologies Used

- React
- TypeScript
- Vite
- Recharts
- SheetJS (xlsx)

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
